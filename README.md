# Carta de Caçador — тренажёр для экзамена ICNF

Подготовка к экзамену на охотничье удостоверение (carta de caçador) в Португалии.

## Источник данных

Все вопросы и правильные ответы взяты из официального вопросника ICNF (Instituto da
Conservação da Natureza e das Florestas):

- https://www.icnf.pt/api/file/doc/2d8ae1589afbdf1e — «Questionário - Manual para exame de carta de caçador»

Банк официально содержит 506 вопросов (не 560). Каждый вопрос переведён на русский
язык с транскрипцией произношения, но перевод и транскрипция — вспомогательные,
ориентиром для правильного ответа остаётся оригинальный португальский текст и ключ
ICNF (отмечен звёздочкой `*` в оригинале, полем `correct` в данных этого репозитория).

## Структура данных (`data/`)

Каждый раздел — отдельный JSON-файл со списком вопросов:

```json
{
  "section_id": "...",
  "section_name_ru": "...",
  "section_name_pt": "...",
  "source": "...",
  "questions": [
    {
      "id": 1,
      "pt": "текст вопроса на португальском",
      "transcription": "транскрипция кириллицей",
      "ru": "перевод на русский",
      "options": [
        {"letter": "A", "pt": "...", "transcription": "...", "ru": "...", "correct": false},
        {"letter": "B", "pt": "...", "transcription": "...", "ru": "...", "correct": false},
        {"letter": "C", "pt": "...", "transcription": "...", "ru": "...", "correct": true}
      ]
    }
  ]
}
```

### Готовые разделы

- [x] `section1_documentos_conceitos.json` — Документы охотника и основные понятия (№1–58)
- [x] `section2_biologia_mamiferos.json` — Биология млекопитающих (№59–167)
- [x] `section3_biologia_aves.json` — Биология птиц (№168–320)
- [x] `section4_especies_nao_cinegeticas.json` — Неохотничьи виды (№321–361)

- [x] `section6_terrenos_cinegeticos.json` — Охотничьи угодья (№413–415)

## Режим тренажёра

1. **Ознакомление** (по разделу, 3 круга подряд, не считается в статистике) — вопрос
   сразу показан с переводом и правильным ответом.
2. **Проверка по разделу** (считается в статистике) — вопрос только на португальском,
   выбор ответа → перевод и транскрипция показываются после ответа. Вопрос считается
   освоенным после 5–6 правильных ответов подряд.
3. **Экзамен** — случайный билет из 20 вопросов вперемешку по всем темам, португальский
   без перевода, порог прохождения 15/20 (как на официальном экзамене).

Прогресс хранится во встроенном хранилище самого приложения (синхронизируется между
устройствами), а не в этом репозитории — здесь только код и банк вопросов.
